# Nursing AI + Cyber website

Website for **Securing AI-Driven Healthcare: Experiential Cyber Learning for Next-Gen Nursing Workforce** at Virginia Commonwealth University.

## GitHub Pages
Upload the HTML files and the `assets` folder to the root of `nursing-ai-cyber.github.io`.

The site intentionally uses public image URLs from VCU and product/manufacturer pages for identification and educational context. Replace these with locally owned project photographs as they become available.
