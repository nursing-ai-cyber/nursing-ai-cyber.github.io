# Nursing AI + Cyber website

Website for **Securing AI-Driven Healthcare: Experiential Cyber Learning for Next-Gen Nursing Workforce**.

## Publishing

1. Download the ZIP from ChatGPT and unzip it.
2. Open the GitHub repository `nursing-ai-cyber/nursing-ai-cyber.github.io`.
3. Select **Add file → Upload files**. Upload the five `.html` files and the `assets` folder (all files, preserving folder structure).
4. Commit to `main`. GitHub Pages is already configured to publish from `main` / `(root)`.
5. Visit https://nursing-ai-cyber.github.io/ after deployment.

## Before sharing with students

- Edit `get-involved.html` to replace the **Survey link coming soon** and **Application link coming soon** placeholders with actual approved links.
- Confirm application deadlines, stipend/eligibility language and device features.
- Review VCU branding and institutional web requirements before adding official logos.
- All SVG illustrations are original simple vector illustrations, not product photos.
- The site is static: no backend, analytics or personal data collection.

## Files

- `index.html` — homepage
- `lab.html` — device showcase
- `fellows.html` — Fellows program
- `get-involved.html` — survey and applications
- `about.html` — team and mission
- `assets/style.css` — shared styles
- `assets/*.svg` — illustrations
